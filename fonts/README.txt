PS Touch PC — Fontes personalizadas

Coloque nesta pasta os arquivos de fonte que deseja disponibilizar ao PS Touch PC.

Formatos reconhecidos nesta versão:
- .ttf — TrueType
- .otf — OpenType
- .ttc — TrueType Collection

O programa procura os arquivos diretamente nesta pasta ao iniciar e carrega as fontes de forma privada para o processo: não instala fontes no Windows nem altera as fontes do sistema. O rodapé da janela mostra quantos arquivos de fonte foram carregados com sucesso. Se adicionar ou remover arquivos enquanto o programa estiver aberto, feche e abra o PS Touch PC novamente.

Somente use fontes que você tenha direito de utilizar. Arquivos inválidos ou incompatíveis são ignorados pelo Windows.

Observação: o carregamento prepara as fontes para os recursos de texto do aplicativo; a ferramenta de texto completa ainda está em desenvolvimento.
